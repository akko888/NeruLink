# Inventory

- Number of devices: Undetermined, the scope should be large (0 - 10 initially).
- Operating systems: Windows, Linux and Android
- Files to support / prioritize: Support any possible file type, the user decides what to prioritize, all files are important.
# Security

- Depending on who uses it, encryption must be flexible (provide options): Secure but reasonable encryption for regular users, and more sophisticated encryption for more advanced users.
- It must prioritize minimum security for any user, even if it isn't massive.
- It must prevent other users from accessing the user's information, unless the user decides otherwise.
# Specifications

### What does it cover?
 - Connect devices over a local network (first version). 
 - Provide a common meeting point for the user's files.
 - Include sufficient security for personal information.
 - Cover most common devices (Desktop, Laptop, Mobile).
 - Make it comfortable to use.
 - Make organization easy (as easy as organizing a directory).
 - Security backups.
 - Visual feedback.

### What does it not cover?
- Connecting devices over the internet (first version).
- Avoids extremely large files (> 20 GB).
- Avoids file versioning for the user's use.

# Minimum success criteria

The program can:
- Synchronize files and handle any conflicts that arise through methods such as Last-Write-Wins or Vector Clocks.
- Provide acceptable security for a regular user.
- Cover at least two operating systems.
- Have visual feedback.
- Have a basic backup system.
